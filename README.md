# SmartATS

SmartATS is an AI-powered Applicant Tracking System (ATS) that assists recruiters throughout the hiring process using AI Agents.

The project focuses on combining deterministic software engineering with LLM-powered reasoning.

## Core Features

- Resume Parsing
- AI Enrichment
- Candidate Search
- Hybrid Retrieval
- Ranking
- Interview Assistance
